# Eren's Cafe ☕

Live Demo: [https://erenscafe.netlify.app/](https://erenscafe.netlify.app/)

## Overview

**Eren's Cafe** is a modern, responsive café website designed to showcase a menu, collect online orders, and provide visitors with a smooth and visually appealing browsing experience. Built using HTML5, CSS3, JavaScript, and Bootstrap 5, it includes user interaction through features like smooth scrolling, image galleries, and order forms.

## Features

- 🍽️ Interactive Menu with item highlights  
- 📝 Order form integration using **EmailJS** (sends orders via email)  
- 📱 Mobile-friendly and responsive design  
- 🔥 Animations and hover effects for better UX  
- 📍 Embedded map and contact section  
- 📷 Gallery section to highlight ambiance and food

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5  
- **Email Integration**: [EmailJS](https://www.emailjs.com/)  
- **Hosting**: [Netlify](https://www.netlify.com/)
